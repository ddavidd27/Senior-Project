FAQ

How do I join a game?
Open a game listing and click “Join”. Once you join, the game will appear in your activity and you’ll be able to follow any updates.
Can I create my own game?
Yes. You can create your own game by choosing the sport, date, time, level, and location so other players can join.
Do I need an account to use Play4All?
You can browse games without an account, but you need to sign in if you want to join a game, create one, or use the chat features.
Are there skill levels?
Yes. Games can be marked as Beginner, Intermediate, or Advanced to help players find the right match for their level.
Can I chat with other players?
Yes. Play4All includes chat features so you can communicate with other users and stay updated about your games.
Is Play4All free to use?
Yes. Play4All is currently free to use for browsing, joining, and creating local sports games.
